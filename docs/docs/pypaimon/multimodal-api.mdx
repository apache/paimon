# Multimodal API

`pypaimon.multimodal` provides a compact interface for scalar, text, vector, and BLOB data on Paimon data-evolution tables without primary keys. A connection wraps a catalog and a default database.

Start with [Multimodal Tables](./multimodal-tables) to connect, define a schema, and add rows. Then follow the guide for your workload:

| Task | Guide |
| --- | --- |
| Create or change rows | [Multimodal tables](./multimodal-tables) |
| Read payloads and coordinate jobs | [Multimodal reads and row IDs](./multimodal-reading) |
| Retrieve text and vector candidates | [Search](./multimodal-search) |
| Store media | [BLOB storage](./blob), [object API](./blob-store), [video frames](./video) |
| Import robotics datasets | [HDF5 and ROSBag](./dataset-ingestion), [LeRobot](./lerobot) |
| Update selected columns | [Data evolution](./data-evolution) |
| Train and process data | [PyTorch](./pytorch), [Ray Data](./ray-data), [Daft](./daft) |
